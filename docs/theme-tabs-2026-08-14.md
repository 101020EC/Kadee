## โจทย์

แถบปุ่ม 3 อัน `รถไทย` / `MY ผิดพิธีการ` / `MY VIS`

## การตัดสินใจ

### D1 — กลไกเปลี่ยนธีม: Token เต็มชุด + attribute บน root ✅

รีแฟกเตอร์สีที่ hardcode ให้เป็น CSS custom properties ทั้งหมด แล้ว override
ด้วยบล็อก `[data-system="violation"]` / `[data-system="vis"]` ทับค่า `:root`

เหตุผล: คุมได้ทุกจุดรวมถึง gradient หัวข้อและเงาปุ่ม, ไม่ซ้ำโค้ด,
และเพราะสี 38/43 จุดใช้ RGB triplet เดียวกันต่างแค่ alpha การรีแฟกเตอร์จึงเป็น
sed แทบล้วน ความเสี่ยงต่ำ

ทางเลือกที่ตัดทิ้ง:
- hue เดียว + `color-mix()` — สั้นกว่าแต่คุมโทนเขียว/ฟ้าให้สวยเท่าม่วงยาก
- แยก CSS 3 ไฟล์ — โค้ดซ้ำ 3 เท่า

### D2 — พื้นหลังหน้าอัปโหลดเป็นรูป ไม่ใช่สีทึบ ✅

ข้อค้นพบ: แถบแท็บโชว์เฉพาะตอน `appState === 'upload'` และหน้านั้นพื้นหลังคือ
`public/hero-bg.webp` (gradient นามธรรม ม่วง/ฟ้า/ส้ม) คลุมฝ้าขาว 45% ที่
`globals.css:581` — ส่วน `--bg-color: #f3f1f8` ใช้แค่หน้าฟอร์มซึ่งแท็บถูกซ่อนแล้ว
ดังนั้น "เปลี่ยนสีพื้นหลัง" ต้องจัดการรูปนี้

**สรุป: ธีมรูปพื้นหลังด้วย `background-blend-mode: color`** (ไม่ใช่ `hue-rotate`)

```css
body.hero-bg::before {
  background: linear-gradient(rgba(255,255,255,.45), rgba(255,255,255,.45)),
              linear-gradient(var(--hero-tint), var(--hero-tint)),
              url('/hero-bg.webp') center/cover no-repeat;
  background-blend-mode: normal, color, normal;
}
```

- ม่วง (รถไทย) = `--hero-tint` โปร่ง / ไม่ใส่เลเยอร์ → รูปเดิมไม่ถูกแตะ
- เขียว + ฟ้า = color blend → เอาเฉพาะความสว่างและรูปทรงจากรูป เฉดสีมาจาก token ล้วน

เหตุผลที่ทิ้ง `hue-rotate`: รูปต้นฉบับมีสองโทนห่างกันคงที่ ~87° การหมุนสีจึงพาแถบ
สีที่สองติดมาด้วยเสมอ — ธีมฟ้าจะได้แถบล่างเป็น **สีเขียว** ซึ่งไปชนกับสีธีม
"MY ผิดพิธีการ" (ผู้ใช้ปฏิเสธข้อนี้ชัดเจน) ส่วน color blend เป็นโทนเดียวทั้งภาพ
การันตีไม่มีสีอื่นหลุด

### D3 — เขียวใช้ color blend เหมือนฟ้า ✅

ทั้งเขียวและฟ้าใช้กลไกเดียวกัน ดูเป็นระบบเดียวกันและแก้ที่เดียว
(ทางเลือกที่ตัดทิ้ง: เขียวใช้ `hue-rotate` ต่อ — ได้มิติสีมากกว่า แต่มีแถบเหลืองมะกอก
โผล่ที่มุมล่างซ้าย และทำให้ 3 ธีมใช้คนละกลไก)

**⚠️ ผลพ่วงที่ต้องออกแบบต่อ:** `background-blend-mode` และ `background-image`
เป็น property ที่ CSS `transition` ไม่ได้ (ต่างจาก `filter` ที่ animate ได้)
→ เอฟเฟกต์ตอนเปลี่ยนธีมต้องใช้เลเยอร์ทับแล้วเฟด/กวาดจอ ไม่ใช่ transition ตรงๆ
ดูหัวข้อเอฟเฟกต์

### D4 — ค่าสีแต่ละธีม: ชุด "สดกว่า" ✅

เกณฑ์เทียบคือคอนทราสต์กับตัวอักษรขาว เพราะปุ่มแท็บที่ active เป็นพื้นทึบอักษรขาว
(`globals.css:140`) — ม่วงเดิม `#7b2cbf` = 7.11:1

| ธีม | activeSystem | accent-primary | คอนทราสต์/ขาว |
|---|---|---|---|
| รถไทย | `thai_vehicle` | `#7b2cbf` (เดิม) | 7.11:1 |
| MY ผิดพิธีการ | `violation` | `#0f7f52` | 5.03:1 |
| MY VIS | `vis` | `#0b74c4` | 4.87:1 |

ทั้งสามผ่าน WCAG AA (≥4.5:1) เขียว/ฟ้าไม่ถึง AAA แต่แลกมากับความสดที่เข้ากับ
พลังของม่วงเดิม (ทางเลือกที่ตัดทิ้ง: เขียว `#10653b` / ฟ้า `#155f84` ที่คอนทราสต์
เท่าม่วงเป๊ะ ~7.1 แต่ออกมาทึมเป็นเขียวป่า/ฟ้าเหล็ก)

token ที่เหลือ derive จาก primary ด้วยสูตรเดียวกับม่วง: `--accent-secondary`
(เข้มขึ้นสำหรับ hover/gradient), `--accent-rgb` (ป้อน `rgba()` ทั้ง 38 จุด),
`--bg-color`, `--input-bg`, `--input-focus`, `--hero-tint`

### D5 — เอฟเฟกต์ตอนเปลี่ยนธีม: ทำสองเส้นทาง ✅

**เส้นทางหลัก — View Transitions API** (เบราว์เซอร์ที่รองรับ)
วงกลมแผ่ออกจากจุดที่ผู้ใช้กด แบบสลับโหมดมืดใน iOS

```js
if (document.startViewTransition) {
  document.documentElement.style.setProperty('--vt-x', `${e.clientX}px`)
  document.documentElement.style.setProperty('--vt-y', `${e.clientY}px`)
  document.startViewTransition(() => flushSync(() => setActiveSystem(sys)))
} else { setActiveSystem(sys) }
```

- ต้องใช้ `flushSync` จาก `react-dom` เพราะ callback ของ View Transitions
  ต้องการให้ DOM อัปเดตเสร็จแบบ synchronous ภายใน callback
- CSS: ปิดครอสเฟดดีฟอลต์ของ `::view-transition-old/new(root)` แล้วใส่ `clip-path`
  วงกลมขยายจาก `var(--vt-x) var(--vt-y)` แทน

**เส้นทางสำรอง — ครอสเฟดสองเลเยอร์** (เบราว์เซอร์ที่ไม่รองรับ)
- hero ซ้อนสองชั้น (`::before` / `::after`) สลับ `opacity` เข้าหากัน ~450ms
  → นี่คือกลไกที่มารับข้อจำกัด `background-blend-mode` transition ไม่ได้ จาก D2
- token สีทั้งเว็บใส่ `transition: background-color, color, box-shadow, border-color`
- แคปซูลใต้ปุ่ม active ไถลไปตำแหน่งใหม่ ไม่กระพริบ

**ข้อควรระวัง:** ห้ามให้สองเส้นทางทำงานพร้อมกัน — ตอน View Transition กำลังเล่น
ต้องปิด CSS transition ของสี ไม่งั้นจะเห็นสีไล่ซ้อนกับวงกลมที่แผ่ออก
ใช้ class ชั่วคราวบน root ระหว่างทรานซิชันคุม

**ทุกเส้นทางใส่ `@media (prefers-reduced-motion: reduce)`** ให้ตัดเอฟเฟกต์
เหลือเปลี่ยนทันที (ตอนนี้โปรเจกต์ยังไม่มี media query นี้เลยสักจุด)

### D6 — เอาไอคอนออก + ปุ่มกว้างเท่ากัน ✅

- ลบไอคอนทั้ง 3: `fa-car-side`, `<CarOutlineIcon />`, `<CarSolidIcon />`
- **ลบตัวคอมโพเนนต์ SVG ทิ้งด้วย** (`page.js:64-84`) เพราะใช้แค่ในแท็บนี้ที่เดียว
  ไม่ปล่อยไว้เป็นโค้ดตาย
- `.tab-btn { flex: 1 }` — สามปุ่มกว้างเท่ากัน แบ่งแถบเต็มความกว้างเป็นสามส่วน

เหตุผล: ไม่มีไอคอนแล้วความกว้างจะเหลือตามข้อความล้วนซึ่งต่างกันมาก
("รถไทย" 6 ตัว vs "MY ผิดพิธีการ" 13 ตัว) ขณะที่บนหน้าอัปโหลดแถบถูกยืด
`width: 100%` อยู่แล้ว (`globals.css:616`) จะเหลือที่ว่างโบ๋ท้ายแถบ
อีกทั้งแคปซูลที่เลื่อน (D5) ขนาดคงที่ทำให้แอนิเมชันไถลดูนิ่งกว่าแบบยืดหด

### D7 — จำธีมลง localStorage ✅

คีย์ `active_system` (ตั้งชื่อให้เข้าชุดกับคีย์เดิม เช่น `proposer_name`,
`approver_selection`) — เดิม `activeSystem` ไม่ถูกจำเลย (`page.js:87`) ทั้งที่ค่าอื่น
จำหมด (`page.js:134-175`) ซึ่งไม่สะดุดตาตอนที่แท็บกระทบแค่แม่แบบเอกสาร
แต่พอมันคุมสีทั้งเว็บ การรีเซ็ตเป็นม่วงทุกครั้งจะรู้สึกเหมือนแอปลืมค่า

**⚠️ ต้องกันสีกระพริบ:** หน้านี้ render ฝั่งเซิร์ฟเวอร์ ถ้าอ่าน localStorage ใน
`useEffect` จะเห็นม่วงวาบหนึ่งเฟรมก่อนสลับเป็นเขียว/ฟ้า
→ ฝังสคริปต์เล็กใน `<head>` ที่ `layout.js:38` เซ็ต `data-system` บน `<html>`
ก่อน hydration (แพตเทิร์นเดียวกับที่เว็บทั่วไปกันโหมดมืดกระพริบ)

## เรื่องที่ตัดสินใจเองระหว่างทำ (ไม่ถามเพิ่ม)

- gradient หัวข้อ (`globals.css:159`, `:659`) ปลายทางเปลี่ยนตาม `--accent-primary`
- แถบเลื่อน (`globals.css:64`, `:68`) และ inline style 4 จุดใน `page.js`

- `data-system` วางบน `<html>` (จำเป็นสำหรับสคริปต์กันกระพริบใน D7)

- ธีมมีผลทั้งเว็บรวมหน้าฟอร์มและ modal จัดการ Template แม้แถบแท็บจะซ่อนไปแล้ว

**ปัญหาที่เจอระหว่างทำและแก้แล้ว**

1. **ธีมที่จำไว้หายทุกครั้งที่รีเฟรช** — effect ในคอมโพเนนต์เดียวกันทำงานตามลำดับที่ประกาศ
   ตัวที่เขียน `localStorage` ทำงานก่อนตัวที่อ่านค่าที่จำไว้ จึงทับด้วยค่าตั้งต้น
   `thai_vehicle` แล้วทับ `data-system` ที่สคริปต์ตั้งไว้ด้วย ตัวอ่านที่ทำงานทีหลัง
   เลยอ่านเจอแต่ค่าที่เพิ่งถูกทับ → แก้ด้วย ref `themeRestored` ให้ข้ามรอบแรก
2. **hydration mismatch** — สคริปต์เติม `data-system` ก่อน React hydrate ทำให้ attribute
   สองฝั่งไม่ตรงกันโดยตั้งใจ → เพิ่ม `suppressHydrationWarning` ที่ `<html>`
3. **โค้ง easing ของครอสเฟด** — `cubic-bezier(0.16, 1, 0.3, 1)` ที่ใช้ทั่วไฟล์เทน้ำหนัก
   ไปช่วงต้นมาก (ผ่านไป 11% ของเวลา ค่าไปแล้วครึ่งทาง) ภาพเดิมวูบหายทันทีแล้วค้างจืดๆ
   → เปลี่ยนเป็น `cubic-bezier(0.4, 0, 0.2, 1)` เฉพาะการครอสเฟด
